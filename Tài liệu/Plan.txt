
[GIAI ĐOẠN 1: THIẾT KẾ CƠ SỞ DỮ LIỆU (DATABASE)]
 ├── Bước 1.1: Định nghĩa các bảng dữ liệu trong SQL Server
 │    ├── Bảng Users (Khách hàng, Admin, Mật khẩu băm, Địa chỉ, Số điện thoại)
 │    ├── Bảng Categories (Danh mục: Tên danh mục, Mô tả, Trạng thái)
 │    ├── Bảng Products (Sản phẩm: Tên, Giá, Giá khuyến mãi, Số lượng tồn kho, Ảnh, FK_CategoryId)
 │    ├── Bảng Orders (Đơn hàng: Mã đơn, Ngày đặt, Tổng tiền, Trạng thái đơn, FK_UserId)
 │    └── Bảng OrderDetails (Chi tiết đơn: FK_OrderId, FK_ProductId, Số lượng mua, Giá tại thời điểm mua)
 ├── Bước 1.2: Cài đặt Entity Framework Core (EF Core) vào Visual Studio
 │    ├── Cài các NuGet package: Microsoft.EntityFrameworkCore.SqlServer và Tools
 │    └── Viết code kết nối chuỗi (Connection String) trong file appsettings.json
 └── Bước 1.3: Tạo các Model C# khớp với bảng SQL và chạy lệnh Migration để tạo Database

[GIAI ĐOẠN 3: LẬP TRÌNH TÍNH NĂNG CỐT LÕI (BACKEND & CONTROLLER)]
 ├── Bước 3.1: Module Xác thực (Authentication & Authorization)
 │    ├── Viết tính năng Đăng ký tài khoản (mã hóa mật khẩu bằng BCrypt/ASP.NET Identity)

 │    ├── Lưu trữ giỏ hàng tạm thời bằng Session hoặc LocalStorage
